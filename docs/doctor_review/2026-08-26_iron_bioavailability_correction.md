# Knowledge Base Change Log — Iron Bioavailability Correction (2026-08-26)

Copied from `docs/doctor_review/knowledge_base_change_log_template.md` per this batch's own convention. This is a tracking artifact, not an approval — the "Approved / Rejected" column is blank until a doctor actually reviews it, even though the underlying data-file change has already been technically implemented (see "Doctor Review Status" and "Doctor Comments" columns below for why).

**Context**: during Phase 2C gold-annotation of the KidsNutriBite evaluation dataset, an exhaustive RAG-corpus search for `EVAL_028` ("What foods can help my child who has iron deficiency anemia?") found two records giving different heme-iron absorption percentages (35% and 15%). This was researched externally against trusted peer-reviewed sources (`docs/evaluation/eval_028_iron_bioavailability_verification.md`), which found both figures are the endpoints of one accepted range ("approximately 15–35%", varying with iron status; Piskin et al. 2022, *ACS Omega*, PMC9219084) rather than one-right-one-wrong values. The project owner then explicitly directed implementing this normalization in the KB text itself, ahead of a formal doctor review, with the explicit instruction to record that gap honestly rather than pretend the change was doctor-approved.
